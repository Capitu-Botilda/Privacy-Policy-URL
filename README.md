# Privacy-Policy-URL

Página pública da política de privacidade (`index.html`), usada como URL de política no aplicativo do WhatsApp.

- Toda mudança entra por pull request.
- `index.html.sha256` guarda o sha256 dos bytes publicados. Quem alterar a página atualiza o arquivo no mesmo PR.
- A branch `main` é protegida contra force-push e exclusão.
